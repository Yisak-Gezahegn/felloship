1. Start XAMPP Control Panel
2. Start Apache and MySQL (both should be green)
3. Open: http://localhost/phpmyadmin
4. Click "New" → Create database: haramaya_fellowship
5. Select the database → Click "Import"
6. Import file: database.sql (this creates all tables)
7. Import file: demo-accounts.sql (this adds demo users)

Solution: Make sure you imported both SQL files

Solution: Login as developer/coordinator to approve the account

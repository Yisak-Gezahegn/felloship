SETUP STEPS:
------------
1. Start XAMPP (Apache + MySQL)
2. Open phpMyAdmin: http://localhost/phpmyadmin
3. Create database: haramaya_fellowship
4. Import: database.sql
5. Import: demo-accounts.sql
6. Create folders: uploads/profiles/, uploads/posts/, uploads/files/
7. Visit: http://localhost/haramaya-fellowship/

WHAT EACH ROLE CAN DO:
----------------------

DEVELOPER:
- Manage all users
- View all reports
- Database backup
- System settings
- Full access

COORDINATOR:

- View section reports

- Create posts/events

SECTION LEADER:

- Submit reports

- Create posts

MEMBER:

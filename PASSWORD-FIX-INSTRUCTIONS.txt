If the script doesn't work, you can:

1. Register a new account at: http://localhost/haramaya-fellowship/register.php
2. Login as that new account
3. Or manually update passwords in phpMyAdmin:
   - Open phpMyAdmin
   - Select haramaya_fellowship database
   - Click on 'users' table
   - Edit the password field with a new hash

To generate a password hash:
   - Create a file: generate-hash.php
   - Add this code:
     <?php echo password_hash('your_password', PASSWORD_DEFAULT); ?>
   - Visit the file in browser
   - Copy the hash
   - Update in phpMyAdmin
